# LRUキャッシュ

## 問題文

最大 `capacity` 件まで値を保持する `LRUCache` を実装してください。

LRU (Least Recently Used) では、容量を超えて新しい値を追加するとき、最も長い間使われていないキーを削除します。

- `get(key)` は、キーが存在すれば値を返し、そのキーを「最近使われた」状態に更新します。
- `put(key, value)` は値を追加または更新し、そのキーを「最近使われた」状態に更新します。
- `put` によって容量を超えた場合、最も長い間使われていないキーを1件削除します。
- 存在しないキーを `get` した場合は `null` を返します。

`get` と `put` を平均 `O(1)` で実現することを目標にしてください。

## 制約

- `1 <= capacity <= 10000`
- `key`, `value` は整数
- `get` / `put` の呼び出し回数は合計100000回以下
- 配列の途中削除や線形探索を毎回行う実装は避けること

## 入力例

```ts
const cache = new LRUCache(2);

cache.put(1, 10);
cache.put(2, 20);
cache.get(1);
cache.put(3, 30);
cache.get(2);
cache.get(3);
```

## 出力例

```text
10
null
30
```

`get(1)` によってキー1が最近使われたため、`put(3, 30)` ではキー2が削除されます。
