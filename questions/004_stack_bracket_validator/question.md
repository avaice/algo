# 括弧列の検証

## 問題文

文字列 `input` が与えられます。

文字列に含まれる `()`, `[]`, `{}` の3種類の括弧が正しく対応しているかを判定する `isBalancedBrackets` を実装してください。

括弧以外の文字は無視してください。

開始括弧は、最後に開かれたものから順に対応する終了括弧で閉じられる必要があります。

## 制約

- `0 <= input.length <= 100000`
- 対象となる括弧は `()`, `[]`, `{}`
- 括弧以外の文字は判定に影響しない
- 期待時間計算量は `O(n)`

## 入力例

```ts
isBalancedBrackets("function test() { return [1, 2]; }");
```

## 出力例

```ts
true
```

別の例:

```ts
isBalancedBrackets("([)]");
// false
```
